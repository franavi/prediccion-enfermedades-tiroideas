# Predicción de enfermedades tiroideas

Trabajo de Fin de Grado centrado en la predicción de enfermedades tiroideas mediante modelos de aprendizaje automático.

Se utiliza el conjunto de datos [Thyroid Disease de UCI](https://archive.ics.uci.edu/dataset/102/thyroid+disease) para clasificar los registros en tres clases:

- Hipotiroidismo.
- Hipertiroidismo.
- Otro diagnóstico.

El repositorio contiene el análisis exploratorio, el preprocesamiento, el entrenamiento y evaluación de los modelos, los modelos finales guardados y una interfaz desarrollada con Streamlit.

## Tecnologías

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn y Streamlit.
